std::string infixToPrefix ( const std::string &  infix)

Converts an infix formula to prefix notation.

Algorithm (reverse / swap / shunting-yard / reverse):

  1. reverse the token list and swap every ( with );
  2. convert the result to postfix with a stack (operator precedence ~ > * > + > >);
  3. reverse the postfix list.
Parameters
infixa well-formed, fully parenthesized infix formula, e.g. ((p+q)*(~r))
Returns
space-separated prefix expression, e.g. * + p q ~ r
Exceptions
std::invalid_argumenton unbalanced parentheses or a bad character
Complexity O(n) time, O(n) space.
