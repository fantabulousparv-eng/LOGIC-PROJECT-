◆ prefixToTreeRecursive()

Node * prefixToTreeRecursive ( const std::string &  prefix)

Builds the parse tree recursively (left to right, one call per token).

The first token is the root. ~ takes one operand, + * > take two, atoms are leaves.

Parameters
prefixspace-separated prefix expression, e.g. * + p q ~ r
Returns
the root of the tree (free it with freeTree())
Exceptions
std::invalid_argumentif the expression is malformed
Complexity O(n) time, O(h) call-stack space (h = tree height).
Warning
Recursion depth equals the tree height; a very deep tree can overflow the stack.
