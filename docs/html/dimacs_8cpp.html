◆ cnfToInfix()

std::string cnfToInfix ( const CnfInfo &  cnf)

Converts a CNF into a fully parenthesized infix formula.

Variable k becomes the atom xk; a negative literal becomes (~xk). Literals of a clause are OR-ed (+) and clauses are AND-ed (*). Both joins are built as a BALANCED binary tree, so the resulting parse tree has height O(log n) instead of O(n) - this keeps the recursive algorithms from overflowing the call stack on large benchmark files.

Complexity O(total literals) time and space.

◆ readDimacs()

CnfInfo readDimacs ( const std::string &  path)

Reads a DIMACS CNF file.

Lines starting with c are comments, p cnf <vars> <clauses> is the header, and every clause is a list of integers terminated by 0 (clauses may span several lines). A % line ends the data (used by some SATLIB files). Empty clauses are ignored.

Parameters
pathpath of the .cnf file (decompress .gz/.bz2 files first)
Exceptions
std::runtime_errorif the file cannot be opened or contains no clauses
