Propositional Logic Parse Trees (CS F214, Assignment 1, Part A)

This project stores a propositional-logic formula as a binary parse tree and runs the algorithms of Tasks 1-6 on it.

Connectives: ~ NOT, + OR, * AND, > implication. Input formulas are fully parenthesized.

Pipeline

infix string –(Task 1)--> prefix string –(Task 2)--> parse tree –(Tasks 3,4,5)--> traversals, height, truth value / truth table –(Task 6)--> measurements and an HTML report.
